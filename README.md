# Где вы потеряли клиента?

Короткое Telegram Mini App из семи экранов для проекта «Продажи в переписке». Человек выбирает ситуацию и свою гипотезу, узнаёт границы бесплатного микроразбора и открывает личный чат автора с черновиком сообщения.

Это готовые статические файлы: сервер приложения, сборка, установка пакетов и токен бота не нужны. Ответы живут только в памяти открытой страницы. Возврат кнопкой «Назад» сохраняет выбор; обновление или закрытие страницы сбрасывает его. Приложение не использует cookies, хранилища, аналитику и загрузку скриншотов. Единственный внешний скрипт — официальный мост Telegram. При финальном переходе выбранные ответы передаются Telegram в ссылке для черновика; источник запуска не передаётся. Скриншоты пользователь отправляет вручную в чате.

## 1. Укажите личный Telegram

Откройте `app.js` в текстовом редакторе. В начале файла, строка 4:

```js
const TELEGRAM_USERNAME = "YOUR_TELEGRAM_USERNAME";
```

Замените только `YOUR_TELEGRAM_USERNAME` на публичное имя **вашего личного аккаунта**, без `@`, пробелов и `https://t.me/`. Кавычки сохраните. Username бота сюда не подходит. Свой username можно посмотреть в настройках Telegram.

Пока placeholder не заменён, финальная кнопка покажет, что переход не настроен, и не откроет чужой чат.

## 2. Посмотрите на компьютере

Откройте папку проекта и дважды нажмите `index.html`. Он откроется в браузере. Все четыре файла должны оставаться рядом. Интернет нужен для загрузки моста Telegram и перехода в чат; без моста сам сценарий продолжит работать как обычная страница.

Пройдите все семь экранов. На экранах выбора «Дальше» становится доступно после ответа. Вернитесь назад и убедитесь, что ответы остались выбранными.

## 3. Опубликуйте через GitHub Pages

1. Откройте репозиторий проекта на GitHub. Загрузите `index.html`, `styles.css`, `app.js`, `README.md` через **Add file → Upload files** в корень репозитория (рядом с `AGENTS.md`). Нажмите **Commit changes**. Если работаете через GitHub Desktop, зафиксируйте эти файлы и нажмите **Push origin**.
2. Откройте **Settings → Pages**.
3. В **Build and deployment → Source** выберите **Deploy from a branch**.
4. В **Branch** выберите ветку, куда загрузили файлы (обычно `main`), и папку **/(root)**. Нажмите **Save**.
5. Дождитесь завершения публикации: статус виден во вкладке **Actions**. Вернитесь в **Settings → Pages** и скопируйте адрес у **Your site is live at / Visit site**. Это итоговый HTTPS URL, обычно вида `https://<имя-на-GitHub>.github.io/sales-in-dm-miniapp/`.
6. Откройте именно этот адрес и проверьте первый экран. Если доступно, включите **Enforce HTTPS**.

Для бесплатного GitHub Pages обычно нужен публичный репозиторий. Для закрытого репозитория доступность зависит от тарифа. После изменений файлов и **Commit changes** сайт обновляется автоматически; при старом содержимом обновите страницу после завершения публикации.

[Официальная инструкция GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## 4. Подключите существующего бота

1. Откройте официальный [BotFather](https://t.me/BotFather) в Telegram и отправьте `/mybots`.
2. Выберите своего существующего бота → **Bot Settings → Configure Mini App → Enable Mini App**. Если Mini App уже включено, выберите редактирование его URL. Названия пунктов могут немного отличаться в версии интерфейса.
3. Отправьте опубликованный **HTTPS URL из GitHub Pages**. Это настройка главного приложения — **Main Mini App**.
4. Если нужна кнопка приложения в меню чата бота, настройте **Bot Settings → Menu Button → Configure menu button** (или командой `/setmenubutton`), укажите тот же HTTPS URL и название кнопки, например «Начать».
5. Откройте профиль бота и запустите приложение.

Настройка Main Mini App нужна для короткой ссылки:

```text
https://t.me/<BOT_USERNAME>?startapp=threads
```

Замените `<BOT_USERNAME>` вместе с угловыми скобками на username **бота** без `@`. Это отдельное имя: в `app.js` указан личный аккаунт автора. Одной настройки Menu Button для этой короткой ссылки недостаточно. При настройке отдельного именованного приложения через `/newapp` ссылка имеет дополнительный путь с именем приложения; для описанного MVP используйте Main Mini App.

Токен бота нигде в файлах указывать не нужно. Код бота, webhook и сервер не требуются.

[Официальная документация Mini Apps](https://core.telegram.org/bots/webapps).

## 5. Проверьте на телефоне перед размещением ссылки

- Откройте HTTPS URL в обычном мобильном браузере, затем ссылку `startapp=threads` в Telegram.
- Пройдите сценарий. Проверьте все 5 ситуаций и 6 гипотез, возвращаясь назад и меняя выбор. Индикатор должен пройти от «1 из 7» до «7 из 7».
- На экране 5 видны ограничения услуги; на экране 6 — граница одного бесплатного эпизода; на экране 7 — просьба скрыть личные данные.
- Проверьте узкий экран, длинные строки, прокрутку шестого экрана и доступность нижней кнопки. На компьютере в инструментах разработчика браузера можно выставить ширину 360, 390 и 430 px.
- Нажмите финальную кнопку: должен открыться **ваш личный чат**, а в поле ввода — сообщение с двумя выбранными ответами. Ничего автоматически не отправляется. Для проверки отправлять сообщение и скриншоты не обязательно.
- Если текст не подставляется, обновите Telegram и проверьте, что получателю можно писать. Подстановка зависит от клиента Telegram и доступности чата. Внешний браузер может сначала предложить открыть Telegram.

Используется официальный формат `https://t.me/USERNAME?text=...`, текст кодируется через `encodeURIComponent`. Внутри Telegram ссылка открывается через `openTelegramLink`, снаружи — как обычная HTTPS-ссылка. [Формат ссылок Telegram](https://core.telegram.org/api/links#public-username-links).

## 6. Как менять тексты

- В `app.js`: `situations` — варианты второго экрана; `hypotheses` — третьего; `pages` — тексты семи экранов; `buttons` — подписи кнопок; `buildMessage` — шаблон черновика.
- Меняйте слова внутри кавычек, сохраняя кавычки, запятые, HTML-теги и порядок семи экранов. Не меняйте `id`, имена функций и обработчики. Варианты ответов автоматически попадут в сообщение.
- В `styles.css` меняются цвета, отступы и размеры. `index.html` содержит оболочку и подключение файлов.
- После правки повторите путь до чата. Не добавляйте поля с персональными данными и не просите загружать скриншоты в приложение.

`AGENTS.md` остаётся исходным описанием продукта.
